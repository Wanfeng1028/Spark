## 一、W6-04：折叠/展开按钮不显眼（P1）

### 现状
- 折叠按钮：`Sidebar.tsx` L380-388，28px 灰色图标按钮（`PanelLeftClose` size-4），位于侧边栏顶部最左边缘，无文字标签，`text-muted-foreground` 配色，视觉上几乎不可见
- 展开按钮：`Sidebar.tsx` L265-266，同规格小图标，无文字

### 修复方案
1. **增大尺寸**：按钮 `size-7`（28px）→ `size-8`（32px），图标 `size-4`（16px）→ `size-4.5`（18px）
2. **提高对比度**：默认态加 `border border-border/60`，图标用 `text-foreground/70`（替代 `text-muted-foreground`）；hover 保持 `bg-accent text-accent-foreground`
3. **折叠态展开按钮加文字**：折叠成 48px 图标栏后，展开按钮保持图标 + `title="展开侧栏"`，并在图标栏底部状态区上方增加一个 **+ 新建会话大按钮**（48px 宽，加号图标居中，`bg-primary` 高对比），让用户一眼看到可操作入口
4. **可选增强**：折叠态图标栏所有图标 hover 时显示右侧浮层 tooltip（文字标签），解决"图标无文字认不出"问题

### 验收

- [ ] 折叠后图标栏有明确的展开按钮和新建会话按钮
- [ ] 图标 hover 有 tooltip

## 二、W6-05：左侧面板内新增「工作区入口」面板（P1）

### 设计定位
参考 VS Code「新标签页 / 资源管理器」形态，在左侧面板内提供**工作区功能入口**。用户点击侧边栏顶部的「工作区」图标（或折叠态下的入口按钮）时，展开一个功能入口列表，替代纯会话列表的单一形态。

### 入口列表设计（基于 Spark 真实能力，禁用假状态）

#### A 组：会话（已实现 ✅）
| 入口 | 动作 | 状态 |
|------|------|------|
| 新建会话 | `createSession()` → 跳 `/session/:id` | ✅ 已有（Sidebar 顶部按钮） |
| 最近会话 | 展开会话列表（当前默认视图） | ✅ 已有 |
| 已归档 | 打开已归档抽屉 | ✅ 已有 |

#### B 组：项目（已实现 ✅）
| 入口 | 动作 | 状态 |
|------|------|------|
| 打开项目文件夹 | `FolderPicker`（最近会话 cwd 去重选项 ≤8，选中后新会话按 cwd 创建） | ✅ 已有（欢迎页 Composer.folder） |
| 浏览文件树 | ＋菜单「浏览文件树」（会话内 attach） | ✅ 已有（Composer 附件） |

#### C 组：导航（已实现 ✅）
| 入口 | 动作 | 状态 |
|------|------|------|
| 搜索 | 跳 `/search` | ✅ 已有（底部导航） |
| 自动化 | 跳 `/automation` | ✅ 已有（底部导航） |
| 设置中心 | 跳 `/settings` | ✅ 已有（底部导航 + Ctrl+,） |
| 命令面板 | 打开 `Ctrl+K` 面板 | ✅ 已有（palette） |
| 三步引导 | 跳 `/onboarding` | ✅ 已有 |

#### D 组：工具（部分待实现 ⚠️ 占位标注）
| 入口 | 动作 | 状态 |
|------|------|------|
| 打开终端 | 无 Web 终端页——**引导 CLI**：显示 `spark` 命令提示 + 复制按钮；或标「即将推出」 | ⚠️ 待实现（建议 v1 做引导，不做假入口） |
| 新建文件 | 引擎有文件写入工具但无 Web UI 入口——标「即将推出」或接引擎 `write` 工具做最小草稿编辑器 | ⚠️ 待实现 |
| 打开云盘文件 | Spark 无云盘能力——**v1 不做**（禁假状态原则），预留扩展点 | ❌ 不在 v1 范围 |

### UI 形态建议
- 左侧面板顶部加一个 **「工作区」下拉/切换**：`会话列表 | 工作区入口` 两个视图（类似 VS Code 活动栏切换）
- 工作区入口视图：垂直列表，分组标题（A 会话 / B 项目 / C 导航 / D 工具），每项 = 图标 + 文字 + hover 高亮
- 已实现项点击即执行；待实现项**不渲染**（遵 Spark「未实现端不渲染」纪律），未来能力到位后追加
- 折叠态下：图标栏新增「工作区」图标（Grid/LayoutGrid），点击展开工作区入口浮层

### 实施步骤
1. `Sidebar.tsx`：新增 `view: 'sessions' | 'workspace'` 状态 + 顶部切换按钮
2. 新增 `WorkspaceEntryPanel` 组件（或 Sidebar 内联）：渲染 A/B/C 组入口
3. 复用现有 handler（createSession / navigate / openArchived / setPaletteOpen）
4. 折叠态图标栏：新增「工作区」图标 + 点击弹出入口浮层
5. W6-04 折叠/展开按钮改造一并完成
6. 更新 `WelcomePage`（可选）：欢迎页 Composer 的「选择文件夹」保持，与左侧面板入口一致

### 验收
- [ ] 左侧面板可在「会话列表 / 工作区入口」两视图间切换
- [ ] 工作区入口含 A/B/C 组所有已实现项，点击可执行对应动作
