## 1. 目标定义：什么叫"Codex/ZCode 桌面的感觉"

对标 Codex 桌面 app（Electron）与 ZCode（ADE）的共性，提炼六个关键词：

| 关键词 | 含义 | 反例（禁止的样子） |
|---|---|---|
| **开发者工具气质** | 高信息密度、克制配色、mono 字体运用、类 VS Code/Linear 的冷静感 | 营销页配色、大圆角卡片堆叠 |
| **转录式会话流** | 会话是"执行记录/控制台日志"：全宽块 + 小角色标签 + 可折叠工具块 | ChatGPT 网页式大头像气泡聊天 |
| **固定工作台** | 侧栏+主区+状态条的 AppShell，面板可折叠，无页面跳转 | 多级路由页面、面包屑导航 |
| **键盘优先** | 全局命令面板、快捷键体系、Esc/Enter 语义清晰 | 只能鼠标点、 hover 才能发现功能 |
| **即时反馈** | 一切异步有状态指示（连接点/运行徽标/进度），无假状态 | 点了没反应、loading 转圈半天 |
| **深色优先** | dark 为默认主题，两套主题都为一级公民 | 只做浅色、深色是补丁 |

**视觉基准**：Codex 桌面 app 截图、ZCode ADE、Claude Code TUI 的内容块行为、Linear/VS Code 的密度与克制。

## 2. 布局规范

```
┌─ titlebar 占位 36px（现显示应用名；Electron 期换自定义标题栏+窗口控制）─┐
┌──────────┬────────────────────────────────────────────┐
│ Sidebar  │ 主区（ChatView 或 阶段四: 会话流+工作区双栏）  │
│ 240px    │                                            │
│ (200-360 │  只有此区域纵向滚动                           │
│  可拖拽,  │                                            │
│  可折叠48)│                                            │
├──────────┴────────────────────────────────────────────┤
│ StatusBar 28px：连接● 模型名 seq 水位 token 累计 主题切换 │
└───────────────────────────────────────────────────────┘
```

- **最小窗口 1280×800**；不做移动端、不做响应式断点（这是桌面应用，不是网站——窗口过小出滚动条即可）。
- **页面级禁止滚动**：html/body 锁 100%（flex/grid 满屏容器）；只有 ChatView 内容区与 Sidebar 列表内部滚动。
- 主区双栏预留：Grid 布局预留 `conversation | workspace` 两列（阶段四接 diff/文件树），先单列占满。
- 浮层（Dialog/Popover/ContextMenu）用 Radix portal，不挤占布局。

## 3. 密度与排版

| 项 | 规则 |
|---|---|
| 基础字号 | UI **13px**；辅助信息 12px；页面级标题 15px（最大不超过） |
| 代码/路径/工具输出 | **一律 mono**（IBM Plex Mono 12.5px），UI 用系统栈 |
| 行高 | 正文 1.5；列表 1.3（紧凑） |
| 间距 | **4/8px 网格**；块内边距 8-12px；区块间距 16px（不超过 24） |
| 列表行高 | 32px（紧凑模式 28px）；Sidebar 会话项 36px |
| 图标 | lucide 16px（状态点 8px 圆） |
| 按钮 | 高 28-32px（紧凑 24px）；主按钮每屏至多一个 |
| 圆角 | 控件 6px；卡片 8px；**最大不超过 12px** |
| 边框 | 1px `--border`；分隔优先用边框与留白，不用阴影 |

**会话流形态（转录式，硬约束）**：消息全宽纵向排列；角色用 12px 灰色小标签（`YOU` / 模型名），**不用大头像、不用大圆角对话气泡**；用户消息用浅色背景块（4px 圆角、全宽）与助手消息区分；工具调用是独立可折叠块（见 §8）。

## 4. 颜色规范（token 定义）

深色默认。中性基调 = shadcn zinc 系；**单一 accent** + 三个语义色，全部走 CSS variables（styles/tokens.css），**禁止组件里出现硬编码 hex**。

| Token | 用途 | dark 建议值 | light 建议值 |
|---|---|---|---|
| `--background/--foreground` | 基底 | `#09090b / #fafafa` | `#ffffff / #18181b` |
| `--muted/--muted-foreground` | 次要信息 | `#18181b / #a1a1aa` | `#f4f4f5 / #71717a` |
| `--border` | 边框/分隔 | `#27272a` | `#e4e4e7` |
| `--primary` | 主按钮/焦点 | `#fafafa`（白按钮黑字，Linear 式） | `#18181b` |
| `--spark-accent` | 运行中/链接/焦点环 | `#818cf8`（indigo-400） | `#4f46e5` |
| `--spark-warn` | 审批挂起/警告 | `#fbbf24`（amber-400） | `#b45309` |
| `--spark-ok` | 成功/完成 | `#34d399` | `#047857` |
| `--spark-err` | 错误/危险 | `#f87171` | `#b91c1c` |

- accent 只用于：运行中指示、焦点环、链接、选中态——**不做大面积强调**。
- 语义色只表达状态，不做装饰。
- 文本对比度 ≥ 4.5:1（两主题都查）。
- **绝对禁止（"AI 生成风"特征清单，判例与细则见 DESIGN.md D2）**：蓝紫渐变玻璃拟态；**暖棕/米色等暖调配色**；**实线细描边 + 内部 backdrop-blur 毛玻璃**的按钮/卡片；渐变；大面积彩色块；多层阴影（浮层至多一层 subtle shadow）；发光边框。

## 5. 交互规范

- **键盘优先**：`Cmd/Ctrl+K` 全局命令面板（切换会话/新建/操作）；`Enter` 发送、`Shift+Enter` 换行、`Ctrl+Enter` 强制 queue、`Esc` 关闭浮层/取消编辑、`Cmd/Ctrl+,` 打开设置。快捷键提示统一写在 Tooltip 与菜单右侧（`⌘K` 样式）。
- **禁用原生 `alert/confirm/prompt`**：一律自绘 Dialog 或内联确认。
- **右键上下文菜单**：会话列表项（重命名/删除）、工具块（复制输出）。
- **危险操作内联确认**：删除按钮点击后变红"确认删除？"（3s 超时还原），不弹窗。
- Tooltip 统一 300ms 延迟出现、即时消失。
- 焦点管理：所有可交互元素 `:focus-visible` 2px accent ring；浮层关闭后焦点归还触发元素。
- **一切异步动作必须有反馈**：按钮点击 ≤150ms 出现 loading 态；提交三态（started/steered/queued）以 toast/内联提示告知。
- **禁止假状态**：UI 状态只能来自事件流（applyEvent）；mock 场景也必须走事件，不允许组件写死演示数据。

## 6. 动效规范

- 只允许**微动效**：opacity/transform，120-160ms ease-out；列表项增删 150ms 淡入淡出。
- 流式光标：`▮` 1s steps(2) 闪烁；审批 resolved 徽标显示 2s 后收起。
- **禁止**：页面/视图转场动画、大位移动画、视差、无限循环动画（loading spinner 除外）、入场编排动画。
- `prefers-reduced-motion: reduce` 时全部动效禁用（保留瞬时状态切换）。

## 7. 反"网站化"黑名单（硬约束，PR 审查逐条对照）

1. 禁止 hero 区/大标题/落地页式空态——空态是紧凑引导块（一段话+主按钮+提示词 chips）。
2. 禁止营销组件：轮播、marquee、大 CTA 按钮、emoji 主视觉、客户 logo 墙。
3. 禁止整页滚动、scroll-snap、锚点导航。
4. 禁止外部链接在应用内打开（一律 `target="_blank"` 交给系统浏览器）。
5. **禁止请求任何外部资源**：字体/图标全本地打包（@fontsource），不引 CDN、不引谷歌字体、无埋点分析。
6. 禁止登录页/cookie banner/营销 footer/版本更新弹窗营销文案。
7. 禁止大头像气泡聊天形态（见 §3 转录式约束）。
8. 禁止乐观更新/本地先行状态（一致性来自 durable 回放，见 02 §6.4）。

## 8. 组件桌面化改造规范（AI Elements copy-in 之后必做）

| 组件 | 桌面化规则 |
|---|---|
| 全部 copy-in 组件 | 密度改造对齐 §3（13px/28-32px 高/8px 内边距/6px 圆角）；样式只改 token 与 Tailwind 类 |
| **ToolCard** | 默认**折叠为一行摘要**：`[图标] 工具名 · 资源路径 · 状态 · 耗时`；点击展开详情；running 时摘要行显示微型 spinner+最后输出片段；错误态红字摘要默认展开 |
| Terminal（bash 输出） | mono 12px；自动滚底（用户上滚则暂停+BackBottom）；缓冲上限 500 行（超出截头）；右上角复制按钮 |
| Diff（edit/write） | unified diff：增行低饱和绿底、删行低饱和红底；文件名栏 mono；hunk 头灰底 |
| **ApprovalCard** | `--spark-warn` 左边框 3px + 浅 warn 背景；三按钮：主=[允许一次]、[总是允许]、[拒绝]（拒绝展开 feedback 输入）；resolved 后徽标 2s 收起为摘要行 |
| Reasoning | 折叠面板，摘要行显示首行+token 数；流式时自动展开、结束自动折叠（手动操作优先） |
| Composer | 三模式（空闲/进行中/审批禁用，见 02 §6.2）；进行中时 [插话][排队][停止] 三个次要按钮+主按钮变 [插话] |
| 状态点 | 8px 圆：绿=空闲、accent 脉动=运行中、amber=等待审批、红=断线 |

## 9. 状态与数据（补充约束）

- 组件**不得直接 fetch**——一切数据经 store selector（违反即架构破坏）。
- 全局连接状态必须在 StatusBar 常显 + 断线时顶部条强提示（回放进度细条）。
- 每个视图/组件的空态、加载态、错误态是**完成定义的一部分**，不允许"以后补"。

## 10. 组件完成定义（DoD，PR 自查清单）

- [ ] props 全类型无 `any`；受控/非受控语义明确
- [ ] 空/加载/错误/禁用 四态齐备

- [ ] 深浅两主题下人工检查（对比度 ≥4.5:1）

- [ ] 消费新事件类型的：applyEvent 单测已加
- [ ] 无外部资源引用（grep 检查 cdn/http 链接）
- [ ] 密度符合 §3（字号/行高/内边距/圆角）

## 11. Electron 桌面化预留（现在就埋，阶段五免返工）

- AppShell 顶部 36px titlebar 占位区（现在放应用名+主题切换，Electron 期替换为自定义标题栏 + 窗口控制按钮）。
- 不用 `window.open`；外部链接 `target="_blank"`。
- 布局不依赖 body 滚动（满屏 flex/grid），`100vh` 用 `100dvh` 兜底。
- 字体/图标本地打包（§7.5）保证离线可用。
- window-state 持久化、系统菜单、托盘：阶段五再接。
