    feat(stage9): 工单 9.2——apps/mobile Expo 骨架（传输适配+主题+三屏导航）
    
    新建 @spark/mobile（Expo SDK 57 + React Native 0.86.3，ADR D20 移动端）：
    - 传输适配层：REST 直接复用协议包 HttpTransport（authToken 双口径）；
      会话级流 RnSessionEventSource 基于 react-native-sse（RN fetch 无流式响应体、
      iOS XHR onprogress 增量不可靠），退避重连复用 DEFAULT_BACKOFF_MS 语义
      （1/2/5/10s 封顶）、since 水位续播、?token= 注入、401/403 经 onError
      上抛走 ERROR_COPY 人话化；配置存 expo-secure-store（token 加密）。
    - Store：zustand + applyEvent 镜像 apps/cli 投影语义；事件入队
      requestAnimationFrame 批处理（参照 web context.tsx 模式）。
    - 主题：DESIGN §13.C token 表 1:1 亮/暗两套，亮色默认、跟随系统；
      底色 #F7F7F7 + 白卡 radius 16 无边框无阴影（J.0）、elevation 单档。
    - 三屏+导航（§13.J 数值）：单栈+抽屉、无 tab bar；会话列表（下拉刷新、
      今天/更早分组、状态点 8px、行高 52、FAB 56）；会话页骨架壳；
      设置页（服务器+token 配置、外观三档、断开连接、配对确认卡）；
      spark://pair 深链解析纯函数（冷启动+运行期双路径）。
    - Jest 首批 29 用例：applyEvent 投影快照与 durable 去重、主题
      亮/暗 token 断言、配对深链合法/非法/缺参。
    - 根管线：eslint 对 Metro/Babel CJS 配置加针对性 overrides（不装新插件）；
      pnpm typecheck/lint/test 三关全绿，pnpm -r scope 含 @spark/mobile。
    - 协议导出面核验：splitSseFrames/envelopeFromSseFrame/DEFAULT_BACKOFF_MS/
      applyEvent/ERROR_COPY 均已从包入口导出，无需补齐。
